# 전쟁 시뮬레이션(태린의 휴대폰)

사이트: https://kdh070907.github.io/korean-war-story/

가상의 상황(전쟁 발발)을 겪는 한 대학생의 휴대폰을 열어 보는 인터랙티브 픽션 사이트입니다.
주인공 이태린은 경희대 국제캠퍼스(용인 서천동) 근처에 자취하는 산업경영공학과 26학번이고, 남자친구 태호는 군 복무 중입니다.
이야기는 2026년 11월 4일(수) 새벽 2시 47분, 태호의 휴가 첫날 새벽에 시작합니다. 약 4분 뒤(3분 55초) 통신망이 끊기며 끝납니다.
경희대학교와 대피소 위치는 실제를 참고했고, 그 밖의 인물·기사·문자는 모두 허구입니다.
서버 없이 HTML/CSS/JavaScript 만으로 동작하고, GitHub Pages 로 무료 공개할 수 있습니다.

## 파일 구조

| 파일 | 내용 | 고칠 일 |
|---|---|---|
| `data.js` | 등장인물, 문자, 전화 대사, 뉴스, 학교 공지, 시간표(timeline) | **여기만 고치면 됩니다** |
| `app.js` | 잠금 해제, 앱 열기, 문자 도착, 전화, 재난문자 등 동작 | 기능을 바꿀 때만 |
| `style.css` | 화면 디자인 | 디자인을 바꿀 때만 |
| `index.html` | 휴대폰 틀 | 거의 없음 |
| `img/` | 배경화면, 갤러리 사진, 기사 사진 넣는 폴더 | 사진 추가할 때 |

## 들어 있는 기능

- **첫 화면**: 창작물 안내 + "휴대폰 열기" 버튼 (소리 재생 허락도 이때 받음)
- **잠금화면**: 쌓인 알림, 위로 밀어서(또는 눌러서) 잠금 해제, 알림을 누르면 바로 그 화면으로
- **홈 화면**: 시계·날씨 위젯, 앱 아이콘, 안 읽은 개수 배지
- **톡(메신저) / 메시지(문자)**: 1:1·단체방, 방 목록은 최근 메시지 순, 읽음 표시 "1", 전송 실패
  - **답장 규칙**: 보낸 말의 "뜻"(안부 질문, 어디야, 누구랑, 같이 있음, 혼자, 집/지하에 있음, 간다/못 간다, 태호, 고마워, 응 …)을 전역 `replyRules` 순서대로 알아듣고 답함
    - 방에 같은 이름의 규칙(`match: "askWhere"`)이 있으면 그 사람 말투로 답함 (엄마·가족방·예린·민지·수빈은 각자 말투)
    - 어떤 뜻에도 안 걸리면 이야기 진행용 `replies`(순서대로) → `fallback`(랜덤). 이미 "누구랑/어디" 말했으면 그걸 다시 묻는 답은 건너뜀
    - "응 / ㅇㅇ / 아니" 같은 짧은 대답은 상대가 바로 전에 물은 말에 맞춰 이해함 (예: "자취방이야?" → "ㅇㅇ" = 자취방에 있음, "혼자 있는 거 아니지?" → "ㅇㅇ" = 같이 있음)
    - 답장 말투는 전쟁 터진 새벽답게 다급하게 ("!!", "ㅠㅠ", "빨리", "제발")
    - 규칙 쓰는 법: `match`(단어 포함) / `exact`(전체 일치) / `re`(정규식), 변형은 돌아가며 사용, 단체방은 `groupReplies` 또는 `{ from, text }`
  - `noReply`: 보내져도 답이 없는 방 · `noInput`: 입력창 대신 "이 채널에서는 메시지를 보낼 수 없습니다"
  - 메시지 `read: true`: 그 메시지만 읽음 처리 (`neverRead` 방에서도 예전 메시지는 읽음으로)
  - 메시지 `photo`: 사진 말풍선 (`img: "img/파일.jpg"` 를 넣으면 진짜 사진, 없으면 `color` 배경 + 설명). 누르면 크게
  - 메시지 `button`: 알림톡 (노란 "알림톡" 띠 + 아래 버튼, 버튼은 "연결할 수 없습니다")
  - 메시지 `reactions: { "❤️": 3, "👍": 2 }`: 말풍선 아래 이모지 반응(카톡 공감처럼)
- **전화**: 최근기록·연락처·키패드, 걸면 전체 화면에서 대사가 자막처럼 나옴 또는 "연결할 수 없습니다"
  - **걸려 오는 전화**: 울리는 동안은 화면 위 배너(아래 화면을 계속 쓸 수 있음), **받으면 전체 화면**으로 바뀌어 대사가 자막처럼 나옴. 안 받거나 거절하면 `ifMissed` 문자가 옴
- **긴급재난문자**: 사이렌 소리 + 진동 + 화면 흔들림 + 전체 팝업
- **뉴스 포털(네이보, 초록 N)**: 속보 띠, 실시간 검색어, 기사, 댓글, 검색. 속보는 화면 위 알림(빨간 테두리, 8초)으로도 뜨고 누르면 기사로
- **학교 앱(경희대)**: 공지사항 (긴급 공지 빨간색, 새 공지 N 표시) — 사이트 대표색은 경희 크림슨(`--accent`)
- **지도**: 경희대 국제캠퍼스 근처 실제 민방위 대피소 8곳(행정안전부 공공데이터) — 주소·수용 인원, 누르면 이름과 주소 표시
- **갤러리 / 메모**
- **상태표시줄**: 시계가 실제로 흐름, 배터리가 줄어듦(0%가 되면 전원이 꺼짐), 신호·망 끊김
- **마지막: 통신망 폭격으로 먹통** (timeline 의 `blackout`): 화면이 지직거리고 "서비스 없음", 통화는 끊기고 문자는 더 이상 오지 않음. 무엇을 눌러도 로딩만 돌다 "응답 없음"(앱이 열리지 않음). 배터리도 더 줄지 않음 (`settings.blackout`)
- **마무리 엔딩** (`settings.ending`): 먹통 `after`초(지금 10초, 실제 시간) 뒤 화면이 꺼지듯 까매지고, `lines` 문장이 한 줄씩(약 2.8초 간격) 나옴 → `final`(크고 굵게) → `after_final` → `credit`(비우면 안 보임) → "처음부터 다시 보기". 화면을 누르면 다음 줄이 바로 나오고, 뒤로가기·Esc 로는 닫히지 않음. 배터리가 다 닳아 전원이 꺼질 때도 같은 엔딩으로 이어짐. 문장 속 `\n` 은 줄바꿈
- **timeline**: "휴대폰 열기" 후 몇 초 뒤에 무슨 일이 일어날지 순서대로 적어 두면 그대로 진행

## 내용 고치는 법

1. `data.js` 를 엽니다. 각 부분 위에 쓰는 법이 주석으로 적혀 있습니다.
2. 글자는 `"큰따옴표"` 안에, 항목 사이에는 쉼표 `,` 를 넣습니다.
3. 고친 뒤 화면이 하얗게 나오면 대부분 **쉼표나 따옴표가 빠진 것**입니다.

claude.ai 에 `data.js` 의 해당 부분을 붙여 넣고 이렇게 부탁하면, 결과를 그대로 붙여 넣을 수 있습니다.

## 휴대폰 디자인: 갤럭시 / 아이폰

- 같은 이야기를 **갤럭시 느낌**과 **아이폰 느낌** 두 가지 디자인으로 볼 수 있습니다.
- 기본 디자인은 `data.js` 의 `settings.phoneStyle` (`"galaxy"` 또는 `"iphone"`) 로 정합니다. (지금은 `"iphone"`)
- 주소 뒤에 붙이면 설정보다 우선합니다: `index.html?style=iphone` / `index.html?style=galaxy`
- **`compare.html`** 을 열면 두 디자인이 나란히 뜹니다. (`compare.html?speed=10` 처럼 속도도 함께 전달)
- 아이폰 디자인: 다이내믹 아일랜드, 아래 홈 바(누르거나 위로 쓸면 홈 / 잠금화면에선 열림), 화면 왼쪽 끝에서 오른쪽으로 쓸면 뒤로,
  잠금화면 손전등·카메라 버튼, 문자 앱의 초록 말풍선, 버튼 묶음이 있는 통화 화면, 가운데 팝업 재난문자
- 아이폰 디자인은 효과음도 아이폰 느낌으로 직접 만든 소리: 세 음 알림음, 보낼 때 "슝", 받을 때 "뽁", 마림바 벨소리, 실제 전화 다이얼 소리, 잠금 해제 딸깍, 재난문자는 긴급 경보 표준음(853Hz+960Hz)
- 애플 로고·실제 아이콘·글꼴 파일은 쓰지 않았습니다. 아이폰·맥에서 볼 때는 기기에 있는 시스템 글꼴이 자동으로 쓰입니다.

## 미리 보기

- 컴퓨터에서 `index.html` 을 브라우저로 열면 바로 볼 수 있습니다.
- 주소 뒤에 `?speed=10` 을 붙이면 timeline 이 10배 빠르게 진행됩니다. (예: `index.html?speed=10`)
- 휴대폰에서 열면 테두리 없이 화면 가득 나옵니다.

## GitHub Pages 로 공개하기

1. GitHub 에서 새 저장소(repository)를 만들고 이 폴더의 파일을 올립니다.
2. 저장소의 **Settings → Pages** 로 갑니다.
3. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/(root)` 로 두고 **Save**.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

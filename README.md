# 어느 대학생의 휴대폰

가상의 상황(전쟁 발발)을 겪는 한 대학생의 휴대폰을 열어 보는 인터랙티브 픽션 사이트입니다.
서버 없이 HTML/CSS/JavaScript 만으로 동작하고, GitHub Pages 로 무료 공개할 수 있습니다.

## 파일 구조

| 파일 | 내용 | 고칠 일 |
|---|---|---|
| `data.js` | 등장인물, 문자, 전화 대사, 뉴스, 학교 공지, 시간표(timeline) | **여기만 고치면 됩니다** |
| `app.js` | 잠금 해제, 앱 열기, 문자 도착, 전화, 재난문자 등 동작 | 기능을 바꿀 때만 |
| `style.css` | 화면 디자인 | 디자인을 바꿀 때만 |
| `index.html` | 휴대폰 틀 | 거의 없음 |
| `img/` | 배경화면, 갤러리 사진, 기사 사진 넣는 폴더 | 사진 추가할 때 |

## 들어 있는 기능

- **첫 화면**: 창작물 안내 + "휴대폰 열기" 버튼 (소리 재생 허락도 이때 받음)
- **잠금화면**: 쌓인 알림, 위로 밀어서(또는 눌러서) 잠금 해제, 알림을 누르면 바로 그 화면으로
- **홈 화면**: 시계·날씨 위젯, 앱 아이콘, 안 읽은 개수 배지
- **톡(메신저) / 메시지(문자)**: 1:1·단체방, 내가 보내면 답장이 옴(`replies`), 읽음 표시 "1", 전송 실패
- **전화**: 최근기록·연락처·키패드, 걸면 대사가 자막처럼 나옴 또는 "연결할 수 없습니다", 걸려 오는 전화(받기/거절/부재중)
- **긴급재난문자**: 사이렌 소리 + 진동 + 화면 흔들림 + 전체 팝업
- **뉴스 포털**: 속보 띠, 실시간 검색어, 기사, 댓글, 검색
- **학교 앱**: 공지사항 (긴급 공지 빨간색, 새 공지 N 표시)
- **지도**: 주변 대피소 핀과 목록
- **갤러리 / 메모**
- **상태표시줄**: 시계가 실제로 흐름, 배터리가 줄어들다 0%가 되면 전원이 꺼짐, 신호·망 끊김
- **timeline**: "휴대폰 열기" 후 몇 초 뒤에 무슨 일이 일어날지 순서대로 적어 두면 그대로 진행

## 내용 고치는 법

1. `data.js` 를 엽니다. 각 부분 위에 쓰는 법이 주석으로 적혀 있습니다.
2. 글자는 `"큰따옴표"` 안에, 항목 사이에는 쉼표 `,` 를 넣습니다.
3. 고친 뒤 화면이 하얗게 나오면 대부분 **쉼표나 따옴표가 빠진 것**입니다.

### Claude 로 내용 쓰기 팁

claude.ai 에 `data.js` 의 해당 부분을 붙여 넣고 이렇게 부탁하면, 결과를 그대로 붙여 넣을 수 있습니다.

> 아래 형식 그대로, 엄마와 주인공의 문자 대화를 새벽 2시부터 3시까지 15개 정도 써 줘.
> (형식: `{ from: "엄마", text: "…", time: "02:31" }` / 내가 보낸 건 `{ me: true, text: "…", time: "…" }`)

## 미리 보기

- 컴퓨터에서 `index.html` 을 브라우저로 열면 바로 볼 수 있습니다.
- 주소 뒤에 `?speed=10` 을 붙이면 timeline 이 10배 빠르게 진행됩니다. (예: `index.html?speed=10`)
- 휴대폰에서 열면 테두리 없이 화면 가득 나옵니다.

## GitHub Pages 로 공개하기

1. GitHub 에서 새 저장소(repository)를 만들고 이 폴더의 파일을 올립니다.
2. 저장소의 **Settings → Pages** 로 갑니다.
3. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/(root)` 로 두고 **Save**.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.
